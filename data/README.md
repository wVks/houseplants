# Датасет houseplants-ru

Создан для учебного SFT-эксперимента. Дата подготовки: 5 ноября 2026 года.

Происхождение: вопросы и краткие правила составлены помощником, затем детерминированно собраны `src.prepare_data`. Это синтетические данные, а не реальные обращения пользователей и не независимо размеченный экспертный корпус. Использовались NC State Extension Plant Toolbox, руководство по контейнерным растениям и UC IPM; ссылки сохранены в `sources.jsonl`. Статьи целиком не копировались, автоматический массовый парсинг не выполнялся.

144 комбинации из 12 растений и 12 тем. На растение 8 train, 1 validation и 3 test. Train содержит три формулировки каждого вопроса, итого 288 строк из 96 ситуаций; validation — 12; test — 36. Варианты одной ситуации в разные части не попадают. Общая схема ответов и тематические правила остаются во всех частях: это ограничивает независимость и внешнюю применимость оценки.

`messages`: system/user/assistant. `question`: пользовательский текст. `reference_facts`, `critical_mistakes` и `reference_answer`: опора для проверки, а не дополнительный вход отвечающей модели. Генератор передаёт только первые два сообщения. Trainer читает только train/validation.

Пересборка: `python -m src.prepare_data`. Проверка без изменения JSONL: `python -m src.prepare_data --audit-only`. Статистика и SHA256: `results/data_audit.json`.

У исходных сайтов сохраняются собственные права на статьи и изображения; изображения в набор не входят. Использование фактов не означает одобрение модели авторами источников. Перед внешним распространением дополнительно проверьте требования вашей учебной организации к синтетическим данным.
